# programmering1-csharp-template
Mall för kursen Programmering1 med C# och .NET 10

1. 
Klicka på “Use this template” uppe till höger och välj “Create a new repository”.


2.
 Välj ditt eget konto och fyll i ett namn för din nya repos. Ex: “prog1-variabler”.
Om du vill skriver du en beskrivning.
Under punkt 2 kan du välja “Private” som visibility.
Klicka på Create repository.


3.
Du hamnar i ditt nya repository som skapats.
Klicka på Code >
> Fliken Codespaces >
> Create codespace on main


4.
Vänta en liten stund på att ditt nya codespace byggs upp.


5.
Nu kan du välja
Code och sen det andra alternativet där det står “on current branch” och “main”.

Det är så du väljer nästa gång du vill gå in och koda i samma projekt/repos.



6.
Du kan få upp frågan om du litar på “authors of the files”. Klicka “Trust”



7.
Nu borde du kunna öppna filen “Program.cs” till vänster och börja koda i den.



8.
För att testköra ditt program klickar du på “Terminal” under skrivytan.
I terminalen skriver du “dotnet run”
Det kan ta några sekunder, sen körs programmet direkt i terminalen.



OBS!
Här kan du ibland stöta på en bugg. Ditt workspace ska lita på källan men samtidigt kan vi få meddelande om att det inte stämmer.
Om du inte får varningar när du stavar fel och inte får förslag på kommandon när du börjar skriva så kan du ha råkat ut för den buggen.

Titta längst ner till höger så ser du en symbol { } Om den har ett kryss så är det fel.


Lösning:	Håll ner ctrl + shift + p
Skriv: Developer: Reload Window. Välj det alternativet för att ladda om sidan.
När sidan laddats om ska det fungera och det lilla krysset på { } ska vara borta.
